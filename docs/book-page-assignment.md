# Book page assignment

In the Windows toolbar, open a page whose printed number is visible. Enter that
number in **Set page:** and press Enter. The page stays in place; navigation and
page labels use the assigned numbering throughout the document.

Clear **Set page:** and press Enter to restore the PDF's original labels. Escape
cancels an edit. Assignments are saved per document, including negative offsets
and mappings whose book page 1 would be at file page 0 or 1.

The PDF itself is unchanged. Existing BookStartPage settings still load.
This toolbar control is currently available in the original Windows app; ng has
no corresponding assignment control.
